# PERMISSION TO FILE CONFERENCE REPORT ON H.R. 4613, DEPARTMENT OF DEFENSE APPROPRIATIONS ACT, 2005

```
   PERMISSION TO FILE CONFERENCE REPORT ON H.R. 4613, DEPARTMENT OF 
                    DEFENSE APPROPRIATIONS ACT, 2005

  Mr. LEWIS of California. Mr. Speaker, I ask unanimous consent that
```
