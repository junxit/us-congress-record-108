# ORDER FOR ADJOURNMENT

```
                         ORDER FOR ADJOURNMENT

  Mr. STEVENS. If there is no further business to come before the 
Senate, I ask unanimous consent the Senate stand in adjournment under 
the previous order, following the remarks to be offered by Senator 
Pryor.
  The PRESIDING OFFICER. Without objection, it is so ordered.
  Mr. STEVENS. I suggest the absence of a quorum.
  The PRESIDING OFFICER. The clerk will call the roll.
  The legislative clerk proceeded to call the roll.
  Mr. PRYOR. Mr. President, I ask unanimous consent the order for the 
quorum call be rescinded.
  The PRESIDING OFFICER. Without objection, it is so ordered.

                          ____________________
```
