# PROGRAM

**Speaking:** Bennett, Robert F. (B000382) [R-UT]

**Measures:** H.R. 2673

```
                                PROGRAM

  Mr. BENNETT. For the information of all Senators, tomorrow, following 
morning business, there will be 60 minutes for debate prior to the 
cloture vote on the Pryor nomination. If cloture is not invoked on the 
nomination, the Senate is expected to resume consideration of H.R. 
2673, the Agriculture appropriations bill. It is hoped that we can 
finish that bill at an early hour during tomorrow's session, and 
therefore Senators should expect a very busy day tomorrow with rollcall 
votes occurring throughout.
```
