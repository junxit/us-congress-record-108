# UNANIMOUS CONSENT AGREEMENT--CORRECTION ON VOTE SEQUENCE

**Speaking:** Baucus, Max (B000243) [D-MT]

```
        UNANIMOUS CONSENT AGREEMENT--CORRECTION ON VOTE SEQUENCE

  The PRESIDING OFFICER. The Senator from Montana.
  Mr. BAUCUS. There is a correction on the vote sequence. Landrieu

amendments. I ask unanimous consent that be modified so there is only 
one Burns amendment, and that is amendment No. 593.
```
